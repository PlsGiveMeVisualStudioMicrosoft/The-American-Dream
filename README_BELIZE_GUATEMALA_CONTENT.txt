THE AMERICAN DREAM — BELIZE & GUATEMALA CONTENT PACK
====================================================

INSTALLATION
------------
Extract the contents of this ZIP directly into the current mod root folder.
Allow Windows to overwrite the two existing country-history files.

This is a changed-files package. It does not include or overwrite unrelated
GitHub work, map files, focus trees for other countries, or Haiti content.

CONTENT
-------
- John Briceño and Bernardo Arévalo as custom country leaders
- Two custom 156x210 ARGB8888 DDS leader portraits
- Real political party names for both countries
- Separate national focus trees: 27 Belize focuses and 30 Guatemala focuses
- Custom national spirits and leader traits
- Belize-Guatemala tension mechanic, repeatable decisions and incident events
- Peaceful ICJ/OAS path, joint-development path and hardline ultimatum path
- Monthly border-incident risk when tension rises above 40
- Realistically scaled 2025 orders of battle
  * Belize: 1st Battalion, 2nd Battalion and Volunteer Battalion
  * Guatemala: six numbered infantry brigades, Mariscal Zavala, Mountain
    Operations, Kaibil Special Forces and the General Felipe Cruz Parachute Brigade
- Starting stability, war support, party popularity, equipment and manpower tuning

IMPORTANT
---------
The files were checked for balanced Clausewitz braces, duplicate focus/event IDs,
missing localisation keys and unresolved Git merge markers. The game executable
cannot be launched in this build environment, so the first in-game launch remains
the final integration test.
