PATCH INSTALLATION
This patch is intended for the previously supplied BG Critical Fix full version.
Copy its folders into the existing TheAmericanDream folder and replace files.

For guaranteed portrait replacement, manually delete these two obsolete files if they still exist:
- gfx/leaders/BLZ/Portrait_BLZ_John_Briceno.dds
- gfx/leaders/GUA/Portrait_GUA_Bernardo_Arevalo.dds

A clean installation of the FULL archive is safer and strongly recommended.
Start a new game.
